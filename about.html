Acerca de GitFlow

GitFlow es un flujo de trabajo estructurado de Git que define un modelo estricto de ramificación diseñado para la gestión de lanzamientos de proyectos. Asigna roles específicos a las diferentes ramas y define claramente cómo y cuándo deben interactuar entre sí.

Este modelo utiliza dos ramas principales de largo plazo: main (código listo para producción) y develop (código de integración para la siguiente versión). Además, se apoya en ramas temporales como feature para nuevas funciones, release para preparar lanzamientos y hotfix para correcciones urgentes en producción.
